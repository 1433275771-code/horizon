## [ChainDrop 蠕虫攻陷逾 1300 个 npm 包](https://www.bleepingcomputer.com/news/security/massive-chaindrop-npm-supply-chain-attack-infects-hundreds-of-packages/) ⭐️ 9.0/10

ChainDrop 蠕虫已攻陷超过 1300 个 npm 包，包括 Keyv、Cacheable 等热门缓存库，合计每月下载量达 20 亿次。攻击者通过入侵 Keyv 维护者的 GitHub 账号，借助看似合法的 GitHub Actions 流程发布了恶意版本。 这是迄今规模最大的 npm 供应链攻击之一，影响了大量开发者及其所在组织。由于受影响的包非常流行且蠕虫能够自我传播，任何安装过受影响版本的开发者都应视系统为已被攻破，并立即轮换所有凭证。 恶意安装脚本 setup.mjs 和 Math\_Symbol.js 会在 npm install 时自动执行，窃取 GitHub、npm、AWS、Kubernetes 等平台的凭证，并可能将恶意代码重新发布到其他维护者的包中。安全公司建议将安装过受影响版本的系统视为已失陷，轮换所有令牌，并将 npm-cache\[.\]com 域名作为失陷指标。

telegram · zaihuapd · 8月5日 03:04

**背景**: npm 是 JavaScript 与 Node.js 生态默认的包管理器，开发者通过 npm install 获取依赖，因此包中的恶意代码会在安装时自动执行。供应链攻击的目标是广泛使用的开源包，以便将恶意软件扩散到下游。此次攻击中，蠕虫利用被入侵的维护者账号和正常的 CI/CD（GitHub Actions）构建流程发布恶意版本，同时保留合法的来源证明，使检测更加困难。

## [专用开源模型以 100 倍更低成本在检索任务上击败 GPT-5.6 Sol](https://neon.com/blog/how-castform-neon-beats-frontier-models-on-price-and-efficiency) ⭐️ 8.0/10
